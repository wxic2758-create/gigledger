常見問題。

簡單說：我們寧可講清楚，也不想過度承諾。

GigLedger 會幫我報稅嗎？+

不會。GigLedger 提供預估與預留目標，不代為申報，也不提供稅務建議。

能連接 Stripe 或 App Store 嗎？+

Pro 支援 Stripe 官方同步，也能匯入 Upwork、PayPal 和 Fiverr 等來源的美元 CSV。App Store 報表同步即將推出。

什麼算固定成本？+

訂閱、軟體、租金、保險、主機等重複發生的成本。一次性花費記為支出；訂閱不要在支出裡再記一次。GigLedger 會記錄營業使用比例，但不判斷某項支出是否能抵稅。

美國以外能用嗎？+

帳本可在全球使用，預留比例由你自設。25%–30% 來自常見的美國自雇做法，不是你所在地的稅法。

我的資料會怎樣？+

使用 Google 登入後，我們會在 Cloudflare D1 儲存 Google 信箱、姓名與你保存的帳本資料。可在 Dashboard 匯出或刪除帳號。

現在可以開始用嗎？+

可以。先不登入試算，再使用 Google 登入保存你的帳本。

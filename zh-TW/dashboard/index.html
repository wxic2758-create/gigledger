免費版

Stripe

請使用可讀取銷售與財務報告、權限最低的 App Store Connect API 金鑰。.p8 私鑰會先加密再儲存，不會回傳到瀏覽器。

貼上 .p8 檔案的完整內容，包括 BEGIN/END PRIVATE KEY。若較低權限角色已足夠，不要使用帳號持有者金鑰。

帳本怎麼運作

  1. 01
    先看你必須付的成本

    加入一項週期性營業成本。就算還沒有客戶付款，GigLedger 也會先算出你的每日底線。

  2. 02
    記錄你賺到多少

    加入收入與平台手續費，淨收入會立即更新。

  3. 03
    看清真正剩下多少

    實際利潤會從淨收入扣除本月固定成本。預留稅款則另外呈現。
